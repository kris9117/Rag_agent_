# Corporate Application Troubleshooting

## Purpose

This guide provides standard troubleshooting for approved enterprise
applications.

## Basic Troubleshooting

Restart the affected application.

Verify network connectivity if the application requires an enterprise
service.

Restart the device if the problem persists.

## Authentication

If the application reports authentication failure, verify the employee
account status.

Do not repeatedly attempt authentication if the account may be locked.

## Application Errors

Record the exact error message when contacting IT support.

Include the application name, device identifier, and approximate time of
the failure when available.

## Escalation

Escalate persistent application failures after basic troubleshooting
has been completed.
