# Corporate Software Installation Policy

## Purpose

This policy defines the approved process for installing software on
managed corporate devices.

## Approved Software

Employees should install software only through approved enterprise
software-distribution mechanisms.

Unapproved software must not be installed on managed corporate devices.

## Installation Problems

If an approved application cannot be installed, verify device
connectivity and available device-management status.

Do not disable security or device-management controls to complete an
installation.

## Licensing

Software requiring an enterprise license must be provisioned through
the approved licensing process.

## Escalation

Contact IT support when an approved application cannot be installed or
requires permissions that the employee does not have.
