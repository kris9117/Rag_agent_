# Setup Guide

## 1. Project Overview

The Enterprise IT Support Agent is a FastAPI-based GenAI application that processes enterprise IT support requests.

The application uses:

- Python
- FastAPI
- OpenAI Responses API
- OpenAI Embeddings API
- FAISS
- BM25
- Cross-Encoder Reranking
- Pytest

## 2. Prerequisites

Install the following:

- Python 3.10 or newer
- Git
- Visual Studio Code
- OpenAI API key

Verify Python:

```powershell
python --version
