# Corporate Laptop Troubleshooting Guide

## Purpose

This guide provides standard troubleshooting steps for employees
experiencing common managed-laptop problems.

## Basic Checks

Confirm that the device is powered on and connected to an available
network.

Restart the affected application before restarting the entire device.

If the device is unresponsive, perform a standard restart when possible.

## Network Problems

Verify that Wi-Fi or the approved network connection is enabled.

If network connectivity is unavailable, check whether other approved
devices can access the same network.

Network problems that prevent corporate applications from operating
should be reported to IT support.

## Performance Problems

Close unnecessary applications and restart the device.

Employees should not install unauthorized system-cleaning or
optimization software.

Persistent performance problems should be reported with the device
hostname and a description of the symptoms.

## Escalation

Contact IT support when:

- The device repeatedly becomes unresponsive.
- Network connectivity remains unavailable.
- Corporate applications cannot be used after basic troubleshooting.
- Hardware failure is suspected.
