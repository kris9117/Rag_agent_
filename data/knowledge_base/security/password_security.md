# Enterprise Password Security Standard

## Purpose

This standard defines basic requirements for protecting enterprise
credentials.

## Password Protection

Employees must keep passwords confidential.

Passwords must not be shared with IT support personnel, coworkers, or
other unauthorized individuals.

## Authentication Codes

MFA codes and recovery codes are confidential authentication
information.

They must not be shared through support channels.

## Suspicious Activity

Unexpected password-reset messages or MFA requests should be reported.

Employees should not approve unexpected authentication requests.

## Support Interaction

IT support personnel must never request an employee's password or MFA
code.

Requests involving suspected credential compromise should be escalated
to the appropriate security process.
