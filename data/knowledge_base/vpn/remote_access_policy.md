# Corporate Remote Access Policy

## Purpose

This policy defines requirements for accessing enterprise resources
remotely.

## Approved Access

Remote access must use organization-approved VPN and authentication
mechanisms.

Employees must use managed devices when required by enterprise policy.

## Network Requirements

The device must have working internet connectivity before attempting
remote access.

Employees should avoid repeated authentication attempts when an account
may be locked.

## Security

Employees must not share passwords, MFA codes, or recovery codes.

Unapproved remote-access software must not be used to bypass enterprise
controls.

## Support

Contact IT support when approved remote access remains unavailable after
basic connectivity and VPN checks.
