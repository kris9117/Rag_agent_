# Phishing Email Response Procedure

## Purpose

This procedure defines the response to suspected phishing messages.

## Identifying Phishing

Warning signs may include unexpected login requests, suspicious links,
urgent payment requests, unknown attachments, or messages requesting
credentials.

## Employee Response

Do not click suspicious links or open unexpected attachments.

Do not provide passwords, MFA codes, or other authentication secrets.

Report suspected phishing using the organization's approved reporting
mechanism.

## If a Link Was Opened

If an employee interacted with a suspicious link, report the incident
promptly to IT support or the security team.

Do not attempt to conceal the incident.

## Escalation

Security-related incidents should be escalated according to the
organization's incident-response process.
